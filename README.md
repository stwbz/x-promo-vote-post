An X post promoting make.fun's make-your-own-bounty, asking readers to vote 1, 2 or 3 for which bounty I should launch first: edits my videos while I sleep, turns voice notes into a finished app overnight, or finds the cheapest flight. `main.ts` copies `POST.json` (the post's URL) to `/output` so the house can read the post itself; it refuses to copy anything that is not an https X status URL.

- Post: https://x.com/stwn_xyz/status/2125451100476297529
- Bounty: https://make.fun/bounty/post-x-promote-make-your-own-bounty-01

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=/output node main.ts
```
